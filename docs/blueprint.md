# **App Name**: Sijariya Portfolio

## Core Features:

- Hero Section: Display name, title, and a brief statement with 'View Projects' and 'Contact Me' buttons, all set against a softly animated background.
- About Section: A split-layout section displaying a short bio and an abstract visual with a soft entrance animation upon scrolling.
- Skills Section: Showcase technical and soft skills within glass-style cards featuring subtle 3D hover effects.
- Projects Section: Present key projects with layered cards, 3D hover motion, and smooth reveal animations, each detailing the tech stack and functionality.
- AI Learning Path Tool: Generative AI tool which receives implicit input from EdifyLearn usage statistics, and other available tools, in order to propose the optimal individualized learning plan.
- Education Timeline: Display academic qualifications and achievements in a vertical timeline format with a fade-in animation.
- Contact Section: A contact section with a refined email, phone, and LinkedIn display, incorporating refined icons and soft hover animations.

## Style Guidelines:

- Primary color: Muted gold (#B3A184) to evoke luxury and sophistication.
- Background color: Deep charcoal (#333333) for a modern, high-end feel.
- Accent color: Slate blue (#708090) to provide a subtle contrast and depth.
- Body font: 'Inter' (sans-serif) for a clean, modern aesthetic. Headline font: 'Alegreya' (serif) to add an editorial touch.
- Use refined icons for contact information and achievements, with a soft hover glow effect.
- Implement generous spacing and a breathable layout for an expensive and calm feel. Utilize split layouts for sections like 'About' to add depth.
- Incorporate soft parallax scrolling, 3D tilt hover effects on cards, and smooth fade and slide-in animations on scroll, ensuring optimal performance with Framer Motion.
